# FitModel

A women's fashion web app (V1): enter your measurements, get a body-shape
profile and a customizable 3D mannequin, then build outfits from your wardrobe.

## Status
🚧 In development. Currently building: body shape engine.

## Planned V1 features
- Measurements → body shape (with percentage blends) + size
- Parametric 3D mannequin (Three.js)
- Wardrobe upload with auto-tagging
- Outfit suggestions by mood and event
- Style quiz

## Stack
FastAPI, SQLite, React, Three.js

## Notes
Body shape categories are common stylist rules of thumb, not a scientific
standard. Results are guides, not rules.
